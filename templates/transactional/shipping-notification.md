# Shipping Notification

Lets the customer know their order is on its way. High anticipation — users want this email.

## When to Send

- When the order ships (carrier pickup scan)
- Optionally: when out for delivery

## Key Elements

- **Tracking number** — with direct link to carrier tracking
- **Carrier name** — which delivery service
- **Estimated delivery date** — when to expect it
- **Items shipping** — especially for split shipments
- **Delivery address** — for verification

## Best Practices

- Link directly to the carrier's tracking page (not your own unless it's genuinely better)
- If the order ships in multiple packages, send separate notifications
- Include the estimated delivery date prominently
- Keep it short — the user just wants the tracking link

## Common Mistakes

- Tracking link that doesn't work yet (carrier hasn't scanned it)
- No estimated delivery date
- Sending before the carrier actually has the package
- Burying the tracking number in a wall of text
