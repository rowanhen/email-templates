# Personalised Recommendations

Usage-based feature suggestions that help active users discover untapped value. Core to product-led growth — drives depth of engagement, not just breadth.

## When to Send

- 2–4 weeks after signup, once baseline usage is established
- Weekly or bi-weekly digest for active power users
- After a specific workflow is completed that unlocks adjacent features
- **Avoid:** first week of onboarding (too early) or to inactive users (wrong message)

## Key Elements

- **Usage acknowledgement** — show you're paying attention ("You've run 14 reports this month")
- **3 targeted recommendations** — no more; curated beats comprehensive
- **Why each one** — one line explaining why it's relevant to *them*
- **One-click access** — deep link directly to the feature, not the dashboard

## Best Practices

- Base recommendations on actual user behaviour, not generic "popular features"
- Cap at 3 recommendations — more creates decision paralysis
- Deep-link directly to the feature or setup flow
## Common Mistakes

- Recommending features they already use
- Too many suggestions at once
- Generic recommendations not tied to their actual usage patterns
- Sending without enough usage data to make credible recommendations (< 1 week)

## Typical Structure

```
Subject: 3 things you haven't tried yet, [Name]

Hi [Name],

Based on your activity this month ([X actions]), here are 3 features
that could save you time:

1. **[Feature A]** — You've been doing [X] manually. [Feature A] automates it.
   [Try it →]

2. **[Feature B]** — Your team uses [Related Feature]. [Feature B] is the
   natural next step.
   [Set it up →]

3. **[Feature C]** — [X]% of users with your workflow use this within 30 days.
   [See how it works →]

Questions about any of these? Just reply.
```

## Metrics to Track

- **Feature adoption rate** — % of recipients who activate a recommended feature
- **Click-to-activate rate** — of those who click, how many actually use it?
- **Depth of engagement** — features used per active user (before vs. after)
- **Retention impact** — does feature adoption improve 90-day retention?
