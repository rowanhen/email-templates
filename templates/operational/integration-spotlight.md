# Integration Spotlight

Ecosystem or partnership email: "Here's how X connects with Y." Use-case driven, showing how two tools or services work together to solve a real problem.

## When to Send

- When a new integration is launched or updated
- As part of an ecosystem onboarding sequence (show users connected tools)
- When usage data reveals an integration is underused but high-value

## Key Elements

- **The use case, not the feature** — lead with a real workflow the integration enables
- **Who it's for** — specific audience or role that benefits most
- **How it works** — brief step-by-step or visual overview
- **Clear CTA** — "Connect now", "Enable integration", or "See how it works"

## Best Practices

- **Lead with the outcome, not the tech** — "Sync your contacts automatically" beats "Bi-directional API sync"
- **One integration per email** — don't combine multiple integrations; dilutes the message
- **Use a concrete example scenario** — abstract capability is less compelling than a named workflow
- **Show the connected logos** — visual pairing reinforces the ecosystem story (HTML email only; omit for plain-text sends)

## Common Mistakes

- Listing integration features instead of showing a workflow
- Sending to everyone instead of segments who use either product
- No setup guidance — "connect now" with no context creates friction
- Making it feel like a product ad rather than a helpful guide

## Typical Structure

```
Subject: [Product A] + [Product B]: [Outcome or use case]

**[Product A] now connects with [Product B]**

[One sentence: the problem this integration solves]

Here's how it works:
1. [Step one]
2. [Step two]
3. [Result — what the user gets]

Best for: [Role or team that benefits most]

[Connect [Product A] + [Product B] →]

Questions? [link or reply]
```

## Metrics to Track

- Click rate on CTA
- Integration activation rate post-email
- Usage of integration 30 days after email
