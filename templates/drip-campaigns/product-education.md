# Product Education Drip

Feature adoption sequence for existing users. Guides customers from basic usage toward the features that drive retention and expansion.

## When to Use
- Triggered after signup/activation, or after a user enables a specific feature
- Typical cadence: 4–6 emails over 2–3 weeks, timed around product milestones
- Separate sequences per product tier or user role — a power user and a new free user need different content

## Sequence Structure

| Email | Trigger/Timing | Focus |
|-------|---------------|-------|
| 1 | Day 1 post-signup | Quick win — the single action that shows value fastest |
| 2 | Day 3 or after first action | Next logical step in the workflow |
| 3 | Day 7 | Power feature they probably haven't found |
| 4 | Day 14 | Collaboration/team feature (expansion hook) |
| 5 | Day 21 | Advanced use case or integration |

## Best Practices
- Trigger on behaviour, not just time — if they've already done the action, skip that email
- Show > tell: GIF, screenshot, or 60-second video outperforms a text walkthrough every time
- One feature per email — covering three features means none get done
- Tie features to outcomes: "Set up auto-reminders → cut follow-up time by half" beats "Introducing: Auto-reminders"
- Include a deep-link CTA directly into the exact feature — remove all navigation friction

## Common Mistakes
- Continuing the sequence for fully-activated users — check feature adoption state before sending
- Feature walkthroughs that read like release notes

## Typical Structure
```
Subject: You haven't tried [Feature] yet — here's what you're missing

Hi [Name],

One feature most people discover too late: [Feature Name].

What it does: [One sentence, outcome-first]

[Screenshot or GIF]

Takes 2 minutes:
1. Go to [Settings → X]
2. [Step 2]

[→ Set up [Feature] now]
```

## Metrics to Track
- **Feature activation rate** — % of email recipients who complete the featured action within 7 days
- **Time-to-activation** — does the sequence reduce days to key feature adoption vs. no sequence?
- **Sequence-to-retention correlation** — do completers churn less at 90 days?
