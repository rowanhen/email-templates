# Order Confirmation

Sent immediately after a purchase. The most opened email type in e-commerce — users actively look for this.

## When to Send

- Immediately after successful payment processing
- Must arrive within seconds

## Key Elements

- **Order number** — prominent, easy to reference
- **Items purchased** — with images if applicable
- **Total paid** — itemised breakdown (subtotal, tax, shipping, discounts)
- **Delivery estimate** — when they'll receive it
- **Billing/shipping addresses** — for verification
- **Next steps** — what happens now
- **Support contact** — how to modify or cancel

## Best Practices

- Plain, clear subject: "Order confirmed — #12345"
- Include everything needed to reference the order without logging in
- Provide a link to order status / tracking
- Make it easy to spot errors (wrong address, wrong item) and fix them
- This is NOT a marketing email — keep it focused on the transaction

## Common Mistakes

- Missing order details (user has to log in to see what they bought)
- Delayed delivery — even 5 minutes feels wrong for a confirmation
- Cramming upsells and promotions into a transactional email
- No way to contact support or modify the order
- Inconsistent formatting of prices and totals

## Typical Structure

```
Subject: Order confirmed — #[Order ID]

Hi [Name],

Thanks for your order! Here's your summary:

[Order Items with prices]

Subtotal: [X]
Shipping: [X]
Tax: [X]
Total: [X]

Delivering to: [Address]
Estimated delivery: [Date]

[Track Your Order Button]

Need to make changes? [Contact link]
```
